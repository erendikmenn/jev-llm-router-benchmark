# Kısa video demo akışı (60–75 saniye)

1. README'de `uv sync --extra dev` ve anahtarsız fixture testini göster.
2. `uv run jev-router environment` ile yalnız anahtarların var/yok durumunu göster; değerleri gösterme.
3. `uv run jev-router calibrate` komutunda threshold'un sadece dev üzerinde seçildiğini vurgula.
4. `uv run jev-router smoke` ve ardından rapordaki kanıt etiketi, kalite farkı, güven aralığı ve mutlak USD alanlarını göster.
5. Demo ekranında bir kolay extraction ve bir zor coding isteğini route et. Girdiyi gönderimden sonra temizleyen ekranı, seçilen tam model kimliğini, süreyi ve “tahmini” maliyet etiketini göster.
6. Son karede `benchmark --mode live --max-usd ...` zorunluluğunu ve “tasarruf sonuç değil; kaliteyle birlikte ölçülen hipotezdir” cümlesini göster.
